# Hackathon_1
Travel-Planner

## Overview
A comprehensive travel planning application that helps users organize and manage their trips efficiently.

## Features
- Create and customize travel itineraries
- Manage destinations and activities
- Track travel expenses
- Collaborate with travel companions
- Get travel recommendations

## Installation
```bash
# Clone the repository
git clone https://github.com/hithaishi28/Hackathon_1.git

# Navigate to project directory
cd Hackathon_1

# Install dependencies
npm install
```

## Usage
```bash
# Start the application
npm start
```
